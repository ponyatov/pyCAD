## 2D CAD for PCB, Electronics & Electrical Design

(c) Dmitry Ponyatov <<dponyatov@gmail.com>> 2026 MIT

PyCAD is a cross-platform 2D CAD system designed specifically for electronics
and electrical engineering. It features a modular architecture supporting
multiple hardware targets and operating systems.
