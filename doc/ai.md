# требования для AI

- давай максимально короткие ответы
- не придумывай ничего, если это явно не запрошено, или не указано в прилагаемых файлах
- не удаляй комментарии если они есть во фрагменте кода
- выдавай код с комментариями
	- `.e` на языке E
	- `.js` на языке JavaScript
	- `.c` `.cpp` на языке C++
