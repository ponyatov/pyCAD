# Спецификация структуры MQTT

Версия: 0.7

Внутреннее и внешнее взаимодействие компонентов аппарата осуществляется через передачу сообщений по протоколу [MQTT](<Сетевые настройки.md#MQTT>).
Брокер MQTT в составе аппарата располагается на среднем уровне (СУ) и реализует следующие функции:
- интеграция BI, верхнего (ВУ), среднего (СУ) и нижнего (НУ) уровней;
- доступ к конфигурации аппарата, флагам состояния и данным мониторинга;
- прямой доступ к функционалу вендингового аппарата;
- управление режимами работы аппарата.

## Общая структура топиков MQTT аппарата

```
Machine               // Топик верхнего уровня для данных всех аппаратов единой системы
	{ID}              // Уникальный идентификатор аппарата
		Config        // Конфигурация аппарата
		States        // Флаги состояния аппарата
		Monitoring    // Данные системы глобального мониторинга аппарата
		Command       // Командный канал - для передачи сообщений и команд между уровнями
		Response      // Канал ответов на сообщения и команды
		HID           // Входные данные от элементов пользовательского интерфейса аппарата
		Control       // Топики для смены режимов работы аппарата и процедуры останова/перезапуска
		Descriptions  // Справочник с текстовыми описаниями статусов компонентов аппарата (для раздела States)
```

## Config
> [Аппаратная конфигурация аппарата](Аппаратная%20конфигурация%20аппарата.md)

- раздел заполняется Нижним уровнем в ходе процедуры включения аппарата;
- раздел используется на всех уровнях для настройки аппаратного и программного обеспечения аппарата;
- используется retained-режим брокера MQTT - сообщение хранится в брокере постоянно и передаётся при подписке

Описание структуры топиков раздела Config:
```
Config        // Конфигурация аппарата
	Power     // Подсистема электропитания
	Env       // Подсистема климатического контроля
	Net       // Сетевые настройки
	Camera    // Подсистема фотовидеоконтроля
	MODBUS    // Шина MODBUS
	IO        // Подсистема ввода/вывода
	Hub       // Спецификация интерфейса хабов
	LED       // Конфигурация LED-подсветки
	Section   // Набор секций аппарата
```

Полное описание раздела Config в файле [Аппаратная конфигурация аппарата](Аппаратная%20конфигурация%20аппарата.md)

## HID
> Входные данные от элементов пользовательского интерфейса аппарата

Описание структуры топиков раздела HID:
```
HID           // Входные данные от элементов пользовательского интерфейса аппарата
	RFID      // Нотификации RFID-карточек
	QR        // Нотификации QR-кодов
```

## Control
> Топики для смены режимов работы аппарата и процедуры останова/перезапуска

Описание структуры топиков раздела Control:
```
Control       // Топики для смены режимов работы аппарата и процедуры останова/перезапуска
	Machine   // Управление режимом работы аппарата, рестарт/останов
	Mid       // рестарт/останов Среднего уровня
	High      // рестарт/останов Верхнего уровня
```

## Descriptions
> Справочник с текстовыми описаниями статусов компонентов аппарата для раздела `Machine/{ID}/States`

- Раздел представляет собой одноуровневый справочник.
- Имя топика - это "путь" до конкретного флага состояния аппарата в дереве MQTT, например, `Global/Status` + знак "_" + значение статуса (ОК, ERROR и т.д.).
- Значение топика - текстовая строка с описанием статуса.

Пример:

| TOPIC MQTT | Значение |
| :-- | :-- |
| Global/Status_OK | Аппарат функционирует в штатном режиме. |
| Global/Status_WARNING | Аппарат функционирует с ошибками. |
| Global/Status_ERROR | Аппарат не функционирует. |
