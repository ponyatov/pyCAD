Конфигурация аппарата задается публикацией службами НУ в топики MQTT брокера по пути `Machine/{ID}/Config/#`.

## Глобальная конфигурация (`Config/Global`)

Ветка `Config/` формируется НУ на основе конфигурации хранимой в НУ. 

| ТОПИК (TOPIC)      | ТИП / СТРУКТУРА | ОПИСАНИЕ                   |
| :----------------- | :-------------- | :------------------------- |
| `Global/ID`        | `string`        | Имя аппарата               |
| `Global/StartDate` | `string`        | Дата ввода в эксплуатацию  |

## Конфигурация секций (`Config/Sections`)

Конфигурация каждой секции представляет собой массив объектов со следующими параметрами:

| ТОПИК (TOPIC)             | ТИП / СТРУКТУРА | ОПИСАНИЕ                                                              |
| :------------------------ | :-------------- | :-------------------------------------------------------------------- |
| `Sections/<index>/Name`   | `string`        | уникальное имя секции (например, `spiral`, `postomat`).               |
| `Sections/<index>/ID`     | `string`        | идентификатор секции.                                                 |
| `Sections/<index>/Type`   | POST            | постомат                                                              |
|                           | SPIRAL          | спиральная секция                                                     |
|                           | WEIGHT          | весовая секция (приём лома)                                           |
|                           | DOZER           | диспенсер сыпучих/жидких материалов (объемный/весовой)                |
| `Sections/<index>/Rows`   | `number`        | число полок                                                           |
| `Sections/<index>/Cols`   | `number`        | число ячеек на полке                                                  |
| `Sections/<index>/IOList` | `string[]`      | массив имен модулей ввода-вывода (IO), закрепленных за данной секцией |
