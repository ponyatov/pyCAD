# Мониторинг вендингового аппарата
Версия: 0.7<br>
К основному документу [00__Спецификация структуры MQTT.md](<00__Cпецификация структуры MQTT.md>)

```
Machine               // Топик верхнего уровня для данных всех аппаратов единой системы
	{ID}              // Уникальный идентификатор аппарата
		Monitoring    // Данные системы глобального мониторинга аппарата
			Global	  // Флаги состояния вендингового аппарата в целом
			Bus       // Флаги состояния шин электропитания
			PSU       // Флаги состояния источников питания (ИП)
			Sections  // Флаги состояния секций
```

## Условные обозначения и соглашения в таблицах

- **ОБНОВЛЕНИЕ** - политика обновления статусов:
	- **const** - постоянное значение - не обновляется, рассылается только в момент старта системы;
	- **change** - обновление при изменении значения;
	- **10s** - регулярное обновление с заданным интервалом.

- **НУ** и **ВУ** - столбцы режимов доступа к топику:
	- **R** только чтение топика;
	- **W** только запись топика.

- **ДЕЙСТВИЕ**
	- **ВУ** - действия верхнего уровня
	- **НУ** - действия нижнего уровня
	- светофор - устройство светосигнальной индикации, светодиодные индикаторы на корпусе аппарата, и/или дублирующее их переключение цветового фона экрана (в режиме отличном от OK)

## Глобальные переменные аппарата
Глобальные переменные аппарата предназначены для отражения состояния аппарата. Они публикуются службами НУ в топики MQTT брокера по пути `Machine/{ID}/Monitoring/Global/#` и имеют следующие значения:

| TOPIC | ЗНАЧЕНИЕ | РАСШИФРОВКА | ОБНОВЛЕНИЕ | НУ | ВУ | ДЕЙСТВИЕ | КОММЕНТАРИЙ |
| :------------ | :------- | :---------- | :---------- | :-: | :-: | :-------- | :---------- |
| `Global/Uptime` | `number` | Наработка, часов | 30m | W | R | | |
| `Global/Power/MainsVoltage` | `number` | Входное напряжение | 1m | W | R | | |
| `Global/Power/Consumption` | `number` | Текущая мощность | 1m | W | R | | |
| `Global/Energy/Day` | `number` | Потреблённая активная энергия за текущие сутки | 1h | W | R | | |
| `Global/Energy/Week` | `number` | Потреблённая активная энергия за неделю | 1d | W | R | | |
| `Global/Energy/Month` | `number` | Потреблённая активная энергия за месяц | 1d | W | R | | |
| `Global/Env/Temp` | `number` | Температура окружающей среды | 5m | W | R | | Усреднённое значение температуры с нескольких датчиков |
| `Global/Env/Hum` | `number` | Числовое значение влажности | 15m | W | R | | Усреднённое значение влажности с датчиков окружающей среды |

## Переменные шин электропитания
Переменные шин публикуются внутри `Machine/{ID}/Monitoring/Bus/{ИндексШины}/#` (индекс от 0) и имеют следующие значения:

| ТОПИК | ЗНАЧЕНИЕ | РАСШИФРОВКА | ОБНОВЛЕНИЕ | НУ | ВУ | ДЕЙСТВИЕ | КОММЕНТАРИЙ |
| :------------ | :------- | :---------- | :---------- | :-: | :-: | :-------- | :---------- |
| `Bus/{index}/Voltage` | `number` | Напряжение на шине | 1m | W | R | | |
| `Bus/{index}/Current` | `number` | Ток на шине | 1m | W | R | | |

## Переменные секции
Общие переменные секций публикуются в топиках `Machine/{ID}/Monitoring/Sections/{ИмяСекции}/#`. Имя секции задается при конфигурации (например, `spiral`, `postomat`).

| Топик | Значения | Расшифровка | Обновление | НУ | ВУ | Действия | Комментарий |
| :------------ | :-------- | :---------- | :--------- | :-: | :-: | :------- | :---------- |
| `Sections/{name}/Uptime/Hours`      | `number` | Наработка, часов          | 30m | W | R | | |
| `Sections/{name}/Uptime/Cycles`     | `number` | Наработка, циклов         | change | W | R | | |
| `Sections/{name}/Uptime/Nominal`    | `number` | Типовая наработка | const | W | R | | |
