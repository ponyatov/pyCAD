# Схема мониторинга вендингового аппарата

- опрос выполняется через подписку на статусы MQTT
	- см. [[Флаги состояния вендингового аппарата]]
- активные программы-опросчики выполняющие сбор данных и отправку в мониторинговые топики MQTT
	- [[#Сетевая подсистема|опрос состояния сетевых устройств по SNMP]]
	- сбор системной информации с хабов (свободное место, память, загрузка, данные по отдельным процессам)

## Хранение истории

- команда [[DumpState]] выполняет выгрузку последнего сохранённого состояния каждого компонента в текстовом формате
	- для ручной отправки данных по диагностике аппарата (по электронной почте)
- команда [[DumpHistory]] выгрузка истории аппарата за указанный диапазон времени
	- расширенная диагностика
	- требует значительный объём памяти для хранения истории, и канал передачи данных в техподдержку
