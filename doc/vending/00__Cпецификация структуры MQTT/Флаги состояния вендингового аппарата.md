# Флаги состояния вендингового аппарата

Версия: 0.7

К основному документу [00__Спецификация структуры MQTT.md](<00__Cпецификация структуры MQTT.md>)

Структура раздела States в дереве топиков MQTT аппарата:
```
Machine               // Топик верхнего уровня для данных всех аппаратов единой системы
	{ID}              // Уникальный идентификатор аппарата
		States        // Флаги состояния вендингового аппарата
			Global	  // Флаги состояния вендингового аппарата в целом
			Bus       // Флаги состояния шин электропитания
			PSU       // Флаги состояния источников питания (ИП)
			Sections  // Флаги состояния секций
			Net       // Флаги состояния сетевых компонентов аппарата
```

## Условные обозначения и соглашения в таблицах

- **ОБНОВЛЕНИЕ** - политика обновления статусов:
	- **const** - постоянное значение - не обновляется, рассылается только в момент старта системы;
	- **change** - обновление при изменении значения;
	- **10s** - регулярное обновление с заданным интервалом.

- **НУ** и **ВУ** - столбцы режимов доступа к топику:
	- **R** только чтение топика;
	- **W** только запись топика.

- **ДЕЙСТВИЕ**
	- **ВУ** - действия верхнего уровня
	- **НУ** - действия нижнего уровня
	- светофор - устройство светосигнальной индикации, светодиодные индикаторы на корпусе аппарата, и/или дублирующее их переключение цветового фона экрана (в режиме отличном от OK)

- **ПОВТОР**
	- ✔️ - **НУ** должен повторить проверку флага при обработке следующей транзакции, или по внутреннему таймеру; выполняется попытка выдачи ТМЦ
	- ❌ - **НУ** блокирует выдачу до устранения проблемы; **ВУ** не отправляет запросы для конкретных ячеек, полок, или секций

## Глобальные флаги состояния

Глобальные флаги состояния предназначены для отражения статуса аппарата в целом. Они публикуются службами НУ в топики MQTT брокера по пути `Machine/{ID}/States/Global/#` и имеют следующие значения:

| :------------ | :------- | :---------- | :------- | :---------- | :------- |-|-|-|
| `Global/Name` | `string` | Уникальное имя аппарата | const | W | R | | | — |
| `Global/StartDate` | `date` | Дата введения в эксплуатацию | const | W | R| | | — |
| `Global/Command` | IDLE | Аппарат находится в ожидании команды ВУ | change | W | R| | | ✔️ |
|| COMMAND | Состояние выполнения команды (выдача ТМЦ) |||| ВУ: отображение изменения состояний ячеек и лифта на мнемосхеме, выделение выданных ТМЦ в списке| | ✔️ |

## Флаги состояния секции
Общие флаги состояния секций публикуются в топиках `Machine/{ID}/States/Sections/{ИмяСекции}/#`. Имя секции задается при конфигурации (например, `spiral`, `postomat`).

| ТОПИК | ЗНАЧЕНИЕ | РАСШИФРОВКА | ОБНОВЛЕНИЕ | НУ | ВУ | ДЕЙСТВИЕ | КОММЕНТАРИЙ | ПОВТОР|
| :------------ | :-------- | :---------- | :------- | :---------- | :------- |-|-|-|
| `Sections/{name}/IsAvailable` | YES      | Секция функционирует в штатном режиме| change | W | R | | | ✔️ |
|| NO       | Секция недоступна | |||| Топик несёт справочный характер, причины недоступности необходимо смотреть по статусам ячеек и портов данной секции|❌|
| `Sections/{name}/Status`     | IDLE     | Секция простаивает            | change | W | R | Можно выполнять новую BI| | ✔️ |
|| DISPENSE | Секция занимается выдачей ТМЦ |||| Откладываем выполнение новой BI до завершения текущей||✔️|
|| LOADING  | В секцию загружают ТМЦ        |||| Нельзя выполнять новую BI | Статус устанавливается извне и блокирует выполнения BI|❌|
| `Sections/{name}/Command`    | IDLE     | Секция находится в ожидании команды ВУ | change | W | R| | | ✔️ |
|| COMMAND  | Секция задействована в выполнении команды (выдача ТМЦ) |||| ||✔️|
|| BLOCKED  | Выполнение команд ВУ заблокировано                     |||| ВУ: "Секция недоступна" ||❌|
